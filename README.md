# Java Platformer Game

A 2D side-scrolling platformer built in Java as a university project at City St George's, University of London.

## Features

- Four levels with gate-based level progression
- Player movement and jumping
- Enemies and fire hazards
- Collectible pickups and speed-boost power-ups
- Lives system
- Main menu, instructions, pause and game-over screens
- Save system with high scores
- Background music and sound effects

## Built with

- Java
- Java Swing (user interface)
- City Engine (City, University of London's 2D game library)

## How to run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Add the City Engine library to the project (File → Project Structure → Libraries).
4. Run the `Game` class in `src/game`.
